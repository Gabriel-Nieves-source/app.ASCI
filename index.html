Instrucciones

  1. Escribe el texto (máximo 100 caracteres).
  2. Elige el sistema numérico: decimal, hexadecimal, octal o binario.
  3. Elige el carácter separador entre códigos.
  4. Toca Generar.
  5. Toca Copiar para llevar los códigos a otra app, o Exportar para guardarlos en un archivo .txt.

El ASCII estándar va de 0 a 127. Letras como á, ñ o € no son ASCII: la app muestra su código Unicode y las marca como fuera del estándar.
